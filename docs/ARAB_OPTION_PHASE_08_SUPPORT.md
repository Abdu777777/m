# المرحلة 08 — الدعم والإشعارات والتقارير
- SupportTicket لتذاكر الدعم وحالاتها وأولويتها وتعيين الموظف.
- UserNotification لإشعارات داخل المنصة وحالة القراءة.
- يضاف إنشاء التذاكر للمستخدم وعرض التذاكر والإشعارات في حسابه.
- إعدادات المنصة القابلة للإدارة موجودة بالفعل عبر PlatformSetting في لوحة الإدارة.
- الإشعارات هنا داخلية فقط؛ لا يوجد إرسال بريد/SMS/Telegram تلقائيًا بعد.
