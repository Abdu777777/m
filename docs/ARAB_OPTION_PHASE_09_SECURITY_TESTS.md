# المرحلة 09 — الاختبارات والتحصين الأمني
## ما أضيف
- اختبارات تحقق من اتجاه وقف الخسارة والهدف لإشارات BUY/SELL.
- اختبار مجال confidence من 0 إلى 100.
- اختبار يمنع بقاء الإشارة منشورة عند حفظها وهي غير معتمدة.
- يوجد GitHub Actions workflow يشغّل Django check، ويتحقق من عدم وجود migrations ناقصة، ويطبق migrations ثم يشغّل الاختبارات عند الدفع إلى main أو فتح Pull Request.
## تحقق مطلوب قبل الإنتاج
- شغّل Workflow وتأكد من نجاح كل الخطوات؛ لا تعتبر الملفات وحدها دليل نجاح.
- اختبر عزل حسابات المستخدمين، صلاحيات KYC، طلبات السحب، التوازن المحاسبي، وإعادة الطلبات (idempotency).
- افحص رفع الملفات بمحتوى مزيف يحمل امتدادًا مسموحًا؛ فحص الامتداد والحجم ليس فحصًا كاملًا لتوقيع الملف.
- أضف تخزينًا خاصًا دائمًا لوثائق الهوية، ومزود بيانات سوق موثوقًا، ومراجعة مستقلة للعمليات المالية قبل إطلاق حقيقي.
