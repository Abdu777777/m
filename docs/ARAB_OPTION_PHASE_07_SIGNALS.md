# المرحلة 07 — إدارة إشارات السوق
- إضافة الإطار الزمني، درجة ثقة تحليلية اختيارية (0-100)، رابط المصدر، وحالة مراجعة مستقلة.
- لا تُنشر الإشارة عبر حفظ النموذج ما لم تكن حالة المراجعة approved.
- إضافة تحقق لاتجاه وقف الخسارة والهدف الأول بالنسبة لسعر الدخول عند استدعاء full_clean().
- مصدر البيانات ووقت المصدر حقول معلنة؛ لا يوجد اتصال آلي بمزود أسعار في هذه المرحلة.
- درجة الثقة رأي تحليلي وليست ضمانًا أو احتمالًا مثبتًا للربح.
## ملاحظة اختبار
يجب تشغيل makemigrations --check وmigrate واختبارات Django في بيئة المشروع قبل النشر. تحقق clean() يعمل عند full_clean()، وليس تلقائيًا عند كل save()؛ لا تعتمد عليه وحده لإدخال بيانات غير موثوقة.
