# عرب أوبشن — خطة التنفيذ ذات المراحل العشر

هذه قائمة تحقق تنفيذية. الحالة لا تعني الاكتمال لمجرد وجود وصف؛ يجب إرفاق اختبار ناجح أو دليل نشر لكل مرحلة.

1. **التأسيس والمراجعة** — فحص الملفات والاعتماديات، ضبط الإعدادات السرية، فصل إعدادات التطوير والإنتاج، فحص الصحة.
2. **الحسابات** — التسجيل والدخول والخروج واستعادة كلمة المرور والتحقق من البريد/الهاتف وحالات الحساب وحدود المحاولات.
3. **الإدارة والصلاحيات** — أدوار منفصلة، أقل امتياز، مصادقة متعددة العوامل للإدارة، سجل تدقيق للعمليات الحساسة.
4. **وسائل الدفع** — CRUD إداري للوسائل، تفعيل/تعطيل، إظهار حسب اتجاه الإيداع/السحب، شبكة وعملة ورسوم وحدود وتعليمات، الاحتفاظ بالسجل القديم.
5. **الطلبات ودفتر الحسابات** — طلبات إيداع/سحب بحالات واضحة، حجز رصيد، معاملات ذرية، idempotency، دفتر مزدوج القيد غير قابل للتعديل الصامت، تسوية ومراجع التحويل.
6. **KYC** — سياسة واضحة، حالات انتظار/قبول/رفض، وصول محدود للوثائق، تخزين خاص مشفر/مقيد، مدد احتفاظ واعتراض.
7. **السوق وأفكار التداول** — أسواق وأصول، مصدر الأسعار وتوقيت آخر تحديث، منع اختلاق الأسعار أو الأداء، سجل النتائج والتصحيحات.
8. **الدعم والإعدادات والتقارير** — تذاكر، إعدادات قاعدة بيانات، موافقات، إشعارات، تصدير تقارير، تسجيل القيم القديمة والجديدة.
9. **الجودة والأمان** — اختبارات وحدات وتكامل وصلاحيات وتزامن، فحص الاعتماديات، CSRF/XSS/SQLi، rate limiting، نسخ احتياطي واختبار استعادة.
10. **النشر والتسليم** — إعداد PostgreSQL دائم، متغيرات آمنة، إنشاء مدير بطريقة آمنة، نشر Railway، اختبار /health/ وتسجيل الدخول، مراقبة وسجل إصدار.

## شروط الإطلاق
- لا كلمة مرور أو سر في Git.
- لا تحويل مالي حقيقي دون مزود دفع تم اختباره ومطابقة التسويات.
- لا أرصدة قابلة للتعديل يدويًا دون قيود محاسبية موثقة.
- لا إطلاق تداول أو إشارات مدفوعة قبل مراجعة قانونية مناسبة.
- لا ادعاء أن الاختبارات نجحت ما لم تُشغّل فعليًا.
