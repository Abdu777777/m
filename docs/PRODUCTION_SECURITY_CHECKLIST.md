# قائمة التحقق الأمنية قبل الإنتاج — Arab Option

دليل إعداد الاستضافة والتخزين الخاص: [RAILWAY_DEPLOYMENT_RUNBOOK.md](RAILWAY_DEPLOYMENT_RUNBOOK.md).

هذه القائمة لا تعني أن المنصة جاهزة للإطلاق؛ يجب تنفيذ البنود والتحقق منها في بيئة النشر الفعلية.

## أسرار وبيئة التشغيل
- [ ] تعيين `SECRET_KEY` عشوائيًا وفريدًا بطول 50 حرفًا على الأقل في إعدادات Railway.
- [ ] ضبط `DEBUG=False`.
- [ ] ضبط `ALLOWED_HOSTS` على أسماء النطاقات الفعلية فقط.
- [ ] ضبط `CSRF_TRUSTED_ORIGINS` على عناوين HTTPS الفعلية فقط.
- [ ] عدم وضع كلمات مرور أو مفاتيح API أو ملفات البيئة السرية في Git.

## قاعدة البيانات والوسائط
- [ ] ضبط `DATABASE_URL` على قاعدة PostgreSQL الإنتاجية.
- [ ] اختبار النسخ الاحتياطي والاستعادة قبل حفظ بيانات حقيقية.
- [ ] تخزين ملفات KYC في `MEDIA_ROOT` خاص أو مخزن خاص مع روابط مؤقتة؛ لا تجعل ملفات الهوية عامة.
- [ ] عند استخدام S3، تفعيل إعدادات الحاوية الخاصة والتحقق من صلاحيات الوصول وتدوير المفاتيح.

## النقل والجلسات
- [ ] التأكد من عمل HTTPS قبل تفعيل التحويل الإجباري إلى HTTPS.
- [ ] مراجعة خصائص Secure وHttpOnly وSameSite لملفات تعريف الارتباط في البيئة الفعلية.
- [ ] تشغيل `python manage.py check --deploy` في بيئة إعداداتها تمثل الإنتاج، ومراجعة كل تحذير بدل تجاهله.

## مراجعة التشغيل
- [ ] التأكد من أن حسابات الإدارة تستخدم كلمات مرور قوية ومصادقة متعددة العوامل حيثما أمكن.
- [ ] مراجعة صلاحيات المشرفين والمراجعين وسجل التدقيق.
- [ ] التحقق من مراقبة الأخطاء وعدم تسجيل الأسرار أو بيانات الهوية في السجلات.
- [ ] عدم تفعيل تحويل الأموال أو التداول الحقيقي قبل مراجعة قانونية وأمنية مستقلة وتكاملات موثوقة.

## بعد كل تغيير
- [ ] نجاح `python manage.py check`.
- [ ] نجاح `python manage.py makemigrations --check --dry-run`.
- [ ] نجاح `python manage.py migrate --noinput` في بيئة الاختبار.
- [ ] نجاح `python manage.py test`.
