# عرب أوبشن | Arab Option

منصة عربية لإدارة تحليلات السوق وأفكار التداول وسير طلبات الدفع، مبنية على Django وقابلة للنشر على Railway.

## الحالة
هذه قاعدة المشروع الحالية، وليست بعد منصة وساطة مالية أو نظام دفع مكتملًا. لا تنفذ تداولًا حقيقيًا أو تحويلات مالية آلية. لا تستخدمها لحفظ أموال الجمهور قبل استكمال دفتر الحسابات، تكاملات الدفع، مراجعة الأمان والامتثال القانوني.

## المكونات الحالية
- صفحة رئيسية لإشارات السوق التي ينشرها المسؤولون.
- أسواق الذهب والفوركس والعملات الرقمية والمؤشرات.
- سجل نتائج يعتمد فقط على النتائج التي يسجلها المسؤولون.
- طلبات اشتراك ومراجعة يدوية.
- Django Admin.
- PostgreSQL عبر DATABASE_URL وSQLite للتطوير المحلي.
- Gunicorn وWhiteNoise وDocker.
- فحص صحة الخدمة عبر /health/.

## الإعداد المحلي
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

## إعداد Railway
- اربط خدمة PostgreSQL واضبط DATABASE_URL من متغيرات Railway.
- اضبط SECRET_KEY بقيمة عشوائية قوية وسرية.
- اضبط DEBUG=False وALLOWED_HOSTS وCSRF_TRUSTED_ORIGINS للنطاق الحقيقي.
- لا تخزن كلمات مرور أو مفاتيح API في GitHub.
- أنشئ حساب المدير من أمر آمن داخل بيئة التشغيل باستخدام createsuperuser.
